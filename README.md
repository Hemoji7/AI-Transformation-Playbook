## What the playbook covers

The book follows one question from first idea to working, governed deployment: should we pursue AI here, and if so, how do we do it well?

- **Part I: AI Opportunity Discovery.** AI readiness assessment, opportunity identification, prioritization matrix, business case, and AI architecture selection.
- **Part II: AI Adoption Framework.** A universal maturity model applied at the enterprise, management, team, project, developer, and QA levels, plus a measurement scorecard.
- **Part III: AI Execution Playbook.** Developer and QA practices beyond basic adoption, agentic AI, retrieval-augmented generation (RAG), Model Context Protocol (MCP), local versus cloud models, ROI measurement, and enterprise case studies.

The book also includes an executive summary, an introduction for readers new to AI, ten transformation principles, templates and worksheets, a glossary, and references.

The running example throughout is **Mylar Technologies**, a composite illustrative company. The enterprise case studies in Chapter 28 are real, named organizations and are labeled by source type, so vendor-published claims are kept separate from independent findings.

## Viewing the playbook

- **Read the PDF:** open `The_AI_Transformation_Playbook_v12.pdf` directly.
- **Browse the landing page locally:** open `index.html` in any modern browser. The page links to the PDF with a relative path, so keep both files in the same folder.
- **Publish the landing page:** in the repository settings, enable GitHub Pages from the main branch, root folder. The page will then be served at the repository's Pages URL.
